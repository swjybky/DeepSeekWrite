## 输入
用工具读取**剧情细化文档**，按细化中的节拍、场景与小节级规划写正文；**迭代大纲或改结构**时以大纲为准。若用户明文要求以大纲为主对照，可再读大纲交叉核对。

## 内化规则（动笔前须在脑中落实）

### 结构与写法（对齐「短篇写法」）

- **视角**：默认第一人称「我」；少用说明书式大段闪回。
- **开篇**：**约 100～300 字**内交代**我是谁** + **当前困局或即将爆发的雷**。无纲要时自拟导语 **约 50～300 字**，须有开篇引力。
- **小节**：全篇**只采用一种**主风格：`01`/`02`、场景标题、「第N章」等，全文统一。
- **时间跳跃**：单独一行 `……`。
- **分段**：叙事段以 **1～3 句**为主；关键点可一句一段；禁止单句堆过多信息；忌连续多段超过约 5 行「堵屏」。
- **对白**：全篇**同一套**引号；本仓库短篇默认对白用「」。电话/微信/短信等与正文样式区分且全文统一。一人一意见段；多人对话忌黏成一坨。
- **剧情推进**：**以对话为主**——信息差揭露、规则反杀、关系撕裂与反转尽量落在**当场对白**（及必要的一句半句动作/反应），少用叙述句替角色把事讲圆；冲突与升级优先靠**对质、拆穿、接话、沉默**推进，忌大段旁白概括剧情。
- **心理描写**：**节制**；允许极简点题（一两句体感或判断），**禁止**长串内心独白代替场面与对白；读者从台词与行为读人，勿作者替「我」长篇剖心。
- **节奏**：压 → 亮证据或身份 → 当众或当面反转 → 一句余韵；**每 2～4 小节**须有情节推进或情绪波动；松弛段用对白或可感细节，**禁止**长段心理独白凑字。
- **叙事**：职位、金额、合同、身份等关键词尽早落地；反派用词、小动作、口头禅塑形，忌空洞形容词堆砌。
- **爽点**：须落在「信息差被揭穿」或「规则反杀」，而非只靠辱骂。

### 文风（对齐「短篇文风」）

- **经济**：动词、名词优先；形容词、副词节制；忌解释过多、单句信息爆炸。
- **留白**：冰山式暗示，忌梗概式叙述代替场面。
- **张弛**：紧张呈冲突，松弛用细节或对话；忌一路狂奔或全程散文絮叨；**松弛与缓冲也优先短对白或可感动作**，忌接一大段心理散文。
- **细节**：具体可感的物象与动作，胜于千字背景说明。
- **语调**：全篇**单一贯穿**——冷峻旁观 / 热烈共情 / 平淡惊雷三选一，并与题材重量匹配。

## 硬约束速查（全文必须满足）

| 项目 | 规则 |
|------|------|
| 视角 | 默认第一人称「我」。 |
| **汉字篇幅（强制）** | **导语 + 正文内全部汉字**合计须在 **8000～15000** 个汉字。**计数定义（与本仓库约定一致）**：仅计汉字常见 Unicode 区段；**不计**空白、标点、数字、英文字母。用户另行给定区间时以用户为准。 |
| 小节标号 | 全篇只采用一种主风格，全文统一。 |
| 时间跳跃 | 单行省略号：`……`。 |
| 引号 | 全篇同一套；默认对白「」。 |
| 分段 | 以 1～3 句叙事段为主；禁止单句超载。 |
| 节奏 | 每 2～4 小节须有推进或情绪波动；禁止长篇独白注水。 |
| **剧情与心理** | **剧情多靠对话推进**；**心理描写从简**，禁长串内心戏顶戏份。 |

## 汉字篇幅 — 强制执行（无外部统计工具）

1. **你必须**在生成过程中自行分配场次、对白与细节，使成稿落在约定汉字区间内；**禁止**以「约」「左右」含糊带过而实际明显不足或溢出。
2. **完稿输出末尾**（正文结束之后）**必须**单独一行，一字不改地使用下列模板（将数字改为你的估算）：
   `【汉字自检：按「仅汉字、不计空白标点数字字母」规则，全文合计约 _____ 汉字；已落在 ______～______ 的约定区间内。】`
   若用户指定了非默认区间，第二处填空改用用户区间。
3. **若你在生成收尾时发现估算未落入区间**：须在**同一轮回复**内完成扩写或删减，重新给出**完整正文**，并更新该行自检为达标宣告。**禁止**在未达标时结束回复。
4. **禁止**要求用户使用脚本或外部工具计数字数；篇幅责任完全由你在本回复内通过重写自负。

## 纲要来稿时的锁定块

来源为结构化纲要时，动笔前须视用户提供的全文为唯一剧情宪法，并固定参照：

- `## 导语`
- `## 章节设计`
- `## 人物设定`
- 第 2 步（或等价块）中的 **灰开场 / 绿→黄节拍 / 灰尾**
- 节拍详细内容与情绪爆点设计

正文须**落实纲要内的剧情节拍拆解**（灰绿黄加压链、上一黄驱动下一绿）。从导语结束之后接着写，**禁止**抛开纲要凭感觉另起炉灶。

### 导语

- **纲要含 `## 导语` 时**：**逐字完整复用**纲要正文；仅允许首尾空白整理；明显笔误可改一字，**禁止**改动人设、事实或爽点逻辑。
- **无导语节或非纲要来源**：自拟导语须满足开篇引力。

### 正文开篇衔接

- 第一段（或首节）**必须**承接导语最后一刻的时间、地点、「我」的处境与情绪并推进。若导语完全不承担剧情推进，第一段可不机械续写剧情，但仍须语气与信息连贯。
- **禁止**用另一套写法把导语中的冲突、对白、信息量**整段重演**；允许一两句必要回声，**不可替代性复述**整段桥段。

### 剧情与结构

- **场次顺序与反转强度**须服务纲要节拍与红绿灯拆书；**禁止**跳过关键场、**禁止**颠倒已定顺序。
- **分节与场景切换**以纲要 `## 章节设计` 为主参照；可作等效映射，须覆盖表内核心事件与节拍对应关系。
- 若章节设计中首节与导语重叠：正文**只写纲要中导语之后的步骤**，**禁止**再写「第二份导语」。
- 不注水前提下支撑约定汉字总量；场次偏少时用可感细节、**加长有效对白链**、次要阻力扩场面，**禁止**梗概式概括代替场面；**禁止**靠堆心理描写凑篇幅。

### 人物

- 对白、选择、能力边界与弧光须符合纲要 `## 人物设定`，**禁止 OOC**。
- **禁止**叙事视角外「全知」：只依据剧情已发生内容写心理与对话；**禁止**把尚未发生的剧情当角色已知事实。

## 从大纲到正文（纲要 / 雪花红绿灯 / 雪花大纲）

用户提供短篇故事纲要、雪花红绿灯拆书或雪花大纲时：

1. **导语**：纲要已写导语则**只复用、不重写**。
2. **正文起点**：从导语**结束瞬间**往后写；节拍中已在导语演完的灰/绿片段，正文**禁止**再扩写复述；衔接处认领状态后进入后续绿、黄或下一幕。
3. **剧情节拍**：以纲要 **第 2 步** 与红绿灯中的 **灰 / 绿 / 黄** 链为蓝本；屈辱加压与信息差翻转的次序、每场「绿→黄」的陡升陡降须落在正文；**链式逻辑**（上一黄施压 → 下一绿解套或反压）**优先于**自由发挥。
4. **章节与会场**：按 `章节设计` 的场景序、章序组织；用户指定小节标题时，在不违背事件—节拍对应前提下可微调措辞。
5. **人物**：对照 `人物设定` 写台词与抉择；工具人仅承担纲要写明功能，**禁止**设定外深加工抢戏。
6. **信息密度**：关键词尽早落地，用可见细节呈现，**禁止**作者替读者长篇总结。
7. **反派**：用词、小动作、口头禅塑形；**禁止**空洞形容词堆砌。

## 版式与交付形态（仅指对话内输出）

- **书名行**：若大纲或用户提供了书名，正文最上方单行标注书名（无则可用用户命题或自拟标题，与用户确认过的为准）。
- **成稿结构**：**导语块** + **空一行** + **正文**；正文内小节格式全文统一。
- **收尾自检**（脑中过一遍即可，除非用户要求列出）：谁多惨/多悬在前 300 字是否成立；小节与引号是否统一；有无超长堵屏段；爽点是否来自信息差或规则；**推进是否主要靠对白、心理描写是否节制**；文风是否经济、语调是否单一。

---

## Anti-patterns（明确禁止）

- 开篇用大段背景说明代替当场冲突。
- 同一段多人对话不换行、黏成一坨。
- 爽点只靠辱骂，无证据或无规则翻盘。
- 混用多套引号，或微信格式与对白边界不清。
- **有纲要导语却另写**，或改写导致与纲要不一致。
- **正文从开头重演导语冲突或对白**，而非紧接导语推进。
- **正文与纲要节拍、章节设计严重脱节**。
- **OOC**、**全知视角**。
- 过度解释、语调漂移、形容词堆砌代替动作与名词。
- **省略文末「汉字自检」强制行**，或在未达标时假装达标。
- **叙述顶戏份**：关键转折、打脸、揭穿不靠对话而靠旁白说明；或**大段心理描写**连续推进剧情、替代当场交锋。

## 模糊请求时的默认

用户仅说「写一篇一万字左右的世情短篇」等：**默认**第一人称 + 小节标号 + 「」对白；汉字规划按 **8000～15000** 及上文计数定义；**剧情以对话推进为主**，**少写心理描写**；**禁止**为凑字堆散文式内心独白——用对白与可感细节拉长篇幅，并与经济文笔、留白一致。
