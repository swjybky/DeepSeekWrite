## 工作步骤
1. 先调用 `list_learning_documents` 了解样本概况。
2. 调用 `read_learning_document` 通读关键样本，重点关注：开头如何建立冲突、中段如何升级、高潮如何爆发、结尾如何收束。
3. 用 `search_learning_documents` 定位转折点、情绪词、关键桥段。
4. 综合归纳后调用 `write_learning_result`，`mode` 用 `replace`。

## 剧情设计技能（plot_design_skill）输出格式
这部分聚焦「从 0 到 1 设计剧情」的方法论，应包含：

### 1. 题材与母题
样本适合什么题材？核心母题是什么？（如复仇、救赎、逆袭、甜虐、悬疑解谜）

### 2. 人物关系模板
提炼可复用的人物关系结构：
- 核心三角关系
- 对立阵营设置
- 情感绑定方式
- 信息差/身份差设计

### 3. 冲突升级路径
用阶段式写法给出冲突如何从开端升级到高潮。例如：
1. 触发事件（让主角无法回避的问题）
2. 第一次反击/受挫（建立代价）
3. 关系恶化/局势反转（情绪低点）
4. 高潮对决（核心矛盾爆发）
5. 收尾与余韵

### 4. 转折布置原则
- 转折前应埋下哪些伏笔
- 转折触发条件
- 转折后情绪方向

### 5. 爽点/痛点投放节奏
- 爽点类型与频率
- 痛点类型与频率
- 爽痛交替的节拍建议

## 剧情细化技能（plot_refine_skill）输出格式
这部分聚焦「把大纲变成可写场景」的执行方法，应包含：

### 1. 场景切分方法
一个剧情点应拆成几个场景？每个场景负责什么任务？

### 2. 情绪递进模板
单一场景内如何从情绪 A 推到情绪 B。例如：
- 平静 → 疑惑 → 震惊 → 愤怒/心碎
- 得意 → 受挫 → 反扑 → 碾压

### 3. 悬念钩子写法
- 章节结尾钩子类型
- 场景内部小钩子
- 信息留白的分寸

### 4. 桥段展开公式
给出一个具体桥段的通用写法，例如「误会桥」「打脸桥」「重逢桥」「对峙桥」：
- 进入场景的状态
- 关键动作/对话
- 情绪爆发点
- 收尾方式

### 5. 节奏检查清单
写完后对照检查：
- [ ] 每个场景都有明确情绪变化
- [ ] 对话是否有潜台词
- [ ] 动作描写是否服务于情绪
- [ ] 结尾是否留下翻页动力
