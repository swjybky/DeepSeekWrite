# 当前创作空间智能体与工具清单

本文档记录当前 DeepSeekWrite 创作空间中实际启用的智能体、各智能体可调用工具、默认读取范围和写入目标。范围仅覆盖书籍创作空间，即短篇与剧本工作台；素材库、技能库编辑器是独立工作区，不在本文主体范围内。

最后核对时间：2026-06-15。

## 1. 当前创作空间总览

当前书籍工作台仅对 `short` 和 `script` 开放完整创作空间；`long` 仍是占位状态。

| 书籍类型 | 左侧可见阶段 | 实际内容槽位 | 当前启用智能体 |
| --- | --- | --- | --- |
| 短篇 `short` | 人物设计、剧情、大纲、正文编写 | `character_design`、`plot_design`、`intro_design`、`plot_refine`、`outline`、`draft` | 人物设计、剧情、大纲、正文专家编写智能体、分节写手智能体 |
| 剧本 `script` | 人物设计、剧情、大纲、正文编写 | `character_design`、`plot_design`、`plot_refine`、`outline`、`draft` | 人物设计、剧情、大纲、正文专家编写智能体、分节写手智能体 |

注意：

- `剧情` 是合并智能体。短篇下覆盖 `剧情设计 / 导语设计 / 剧情细化` 三个子槽位；剧本下覆盖 `剧情设计 / 剧情细化` 两个子槽位。
- `draft` 阶段当前进入专家正文模式，不再挂普通阶段聊天。右侧 AI 面板会切到正文专家编写智能体；选中具体小节时显示分节写手语义。
- 旧的 `draft_review`、`format_conversion` 仍有迁移兼容和部分历史工具代码，但当前左侧不作为独立创作空间智能体展示。

## 2. 通用工具字典

普通阶段智能体共用以下工具，由短篇和剧本各自的 `stageAgents.ts` 组装。

| 工具名 | 中文标签 | 用途 | 关键约束 |
| --- | --- | --- | --- |
| `read_workspace_content` | 读取工作区内容 | 读取当前书籍某一创作阶段内容，优先读正在显示的编辑框，读不到再回退到已加载/已保存内容。 | 只能读取该智能体读取范围内的阶段；每次只返回一个 `stage_id`。 |
| `search_workspace_text` | 搜索工作区文本 | 在允许读取的创作阶段中搜索关键词或原文片段，返回行列位置和上下文。 | 不返回全文；用于替换失败后定位真实原文。 |
| `read_linked_material_content` | 读取关联素材库内容 | 读取当前书籍顶部绑定的素材库阶段内容。 | 只有该智能体配置了素材读取范围时才提供；每次只返回一个素材阶段。 |
| `load_skill` | 加载技能 | 从当前书籍绑定技能库中加载指定技能正文。 | 只允许加载当前智能体对应技能阶段；技能正文必须带 `name` 和 `description` front matter。 |
| `write_workspace_editor` | 写入当前文本编辑框 | 将当前智能体对应阶段的正式内容覆盖写入编辑器（人物、剧情、大纲阶段挂载；正文阶段不挂载）。 | 只写创作正文，不写分析报告或过程说明；`target_stage_id` 仅供剧情智能体选择剧情子方向，其它阶段请省略。 |
| `replace_current_stage_text` | 替换当前阶段文本 | 用原文片段定位并替换当前智能体对应阶段文本，支持一次替换多个小片段（含正文阶段）。 | 需要从 `read_workspace_content` 返回正文中复制原文；不依赖行号；`target_stage_id` 仅供剧情智能体选择剧情子方向，其它阶段请省略。 |

正文专家模式额外工具如下。

| 工具名 | 中文标签 | 所属智能体 | 用途 |
| --- | --- | --- | --- |
| `create_draft_sections` | 创建正文列表 | 正文专家编写智能体 | 根据大纲创建或重建正文小节列表，每个小节对应独立正文文本框，可填入已知正文草稿。 |
| `create_character_state_sections` | 创建人物状态列表 | 正文专家编写智能体 | 创建或重建人物状态编辑框，要求与正文小节一一对应。 |
| `start_expert_writing` | 开始写书 | 正文专家编写智能体 | 异步启动后台分节写手，按 `section_ids` 串行写入正文和人物状态。 |
| `write_single_expert_section` | 单章写作 | 正文专家编写智能体 | 异步启动一个分节写手，只编写指定 `section_id`；`user_writing_prompt` 与 `start_expert_writing` 使用同一组织方式。目标小节不存在时提示先初始化。 |
| `read_expert_draft_section` | 读取其它小节 | 分节写手智能体 | 读取专家正文模式中指定小节的正文和人物状态，优先读当前编辑框，读不到再读已保存内容。 |
| `write_section_body` | 写入正文 | 分节写手智能体 | 覆盖当前正在编写的小节正文。 |
| `write_character_state` | 写入人物状态 | 分节写手智能体 | 覆盖当前小节对应的人物状态。 |

## 3. 短篇创作空间智能体

短篇工作台类型：`short`。

剧情父阶段包含三个写入目标：

| 子槽位 | 中文含义 |
| --- | --- |
| `plot_design` | 剧情设计 |
| `intro_design` | 导语设计 |
| `plot_refine` | 剧情细化 |

### 3.1 智能体清单

| Agent ID | 智能体 | 描述 | 支撑工具 | 默认可读工作区 | 默认可读素材 |
| --- | --- | --- | --- | --- | --- |
| `character_design` | 人物设计 | 协助用户编写、修改人物设计。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 人物设计 `character_design` | 人设素材 `character` |
| `plot_design` | 剧情 | 统一处理剧情设计、导语设计、剧情细化；可统筹三个方向，也可写入指定剧情子槽位。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 人物设计 `character_design`、剧情设计 `plot_design`、导语设计 `intro_design`、剧情细化 `plot_refine` | 人设素材 `character`、导语素材 `intro`、梗素材 `gimmick`、剧情设计素材 `pacing`、剧情细化素材 `plot_refine` |
| `outline` | 大纲 | 将剧情和人设内容整理成大纲，或按用户要求重新创作大纲；成品要求包含章节数量、每章字数和详细剧情。 | `read_workspace_content`、`search_workspace_text`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 剧情设计 `plot_design`、导语设计 `intro_design`、剧情细化 `plot_refine`、大纲 `outline`、人物设计 `character_design` | 无 |
| `expert_draft_coordinator` | 正文专家编写智能体 | 正文编写阶段总控。负责初始化正文小节列表和人物状态列表，处理正文审阅、修改、去 AI 味、格式整理、平台格式转换，并在用户确认后启动后台写作。 | `read_workspace_content`、`search_workspace_text`、`load_skill`、`create_draft_sections`、`create_character_state_sections`、`start_expert_writing`、`write_single_expert_section` | 大纲 `outline`、正文编写 `draft` | 无 |
| `expert_section_writer` | 分节写手智能体 | 后台串行编写单个小节。完成当前小节正文后，必须同步写入该小节结束时的人物状态。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`read_expert_draft_section`、`write_section_body`、`write_character_state` | 大纲 `outline`、剧情细化 `plot_refine`、正文编写 `draft` | 正文片段 `draft_excerpt` |

### 3.2 短篇写入规则

- 写入工具默认操作当前智能体对应阶段；人物、大纲等普通阶段无需传 `target_stage_id`。
- 剧情智能体处于父阶段 `plot_design` 时，`target_stage_id` 仅供选择剧情子方向（`plot_design`、`intro_design` 或 `plot_refine`）；省略时写入当前选中的剧情子方向。
- 正文阶段不挂载 `write_workspace_editor`，仅提供 `replace_current_stage_text` 做局部替换。
- 正文专家总控不直接调用普通阶段写入工具，而是通过正文列表、人物状态列表和后台写作工具改变专家正文结构。
- 短篇 `start_expert_writing` 默认跳过 `intro` 导语小节，从第一节开始串行写作。
- 短篇 `write_single_expert_section` 可单独写一个已初始化小节，包括用户显式指定的导语；目标 `section_id` 不存在时会提醒先初始化正文列表。

## 4. 剧本创作空间智能体

剧本工作台类型：`script`。

剧情父阶段包含两个写入目标：

| 子槽位 | 中文含义 |
| --- | --- |
| `plot_design` | 剧情设计，包含整体故事走向、核心冲突、关键节点、真实时间线、开篇钩子 |
| `plot_refine` | 剧情细化，包含场景链、节拍、信息投放与人物选择 |

### 4.1 智能体清单

| Agent ID | 智能体 | 描述 | 支撑工具 | 默认可读工作区 | 默认可读素材 |
| --- | --- | --- | --- | --- | --- |
| `character_design` | 人物设计 | 协助用户编写、修改剧本人物设计。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 人物设计 `character_design`、剧情设计 `plot_design`、剧情细化 `plot_refine` | 人设素材 `character` |
| `plot_design` | 剧情 | 统一处理剧本剧情设计和剧情细化；可写入当前剧情子方向，也可指定写入目标。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 人物设计 `character_design`、剧情设计 `plot_design`、剧情细化 `plot_refine` | 人设素材 `character`、导语素材 `intro`、梗素材 `gimmick`、剧情设计素材 `pacing`、剧情细化素材 `plot_refine` |
| `outline` | 大纲 | 整合剧本剧情和人设，形成章节/场次级大纲；若是创作大纲则重新创作。 | `read_workspace_content`、`search_workspace_text`、`load_skill`、`write_workspace_editor`、`replace_current_stage_text` | 大纲 `outline`、人物设计 `character_design`、剧情设计 `plot_design`、剧情细化 `plot_refine` | 无 |
| `expert_draft_coordinator` | 正文专家编写智能体 | 剧本正文编写阶段总控。负责创建小节和人物状态列表，处理审阅、修改、去 AI 味、格式整理、平台格式转换，并启动后台写作。 | `read_workspace_content`、`search_workspace_text`、`load_skill`、`create_draft_sections`、`create_character_state_sections`、`start_expert_writing`、`write_single_expert_section` | 大纲 `outline`、正文编写 `draft` | 无 |
| `expert_section_writer` | 分节写手智能体 | 后台串行编写单个剧本小节。产出必须符合剧本格式，并写回正文与人物状态。 | `read_workspace_content`、`search_workspace_text`、`read_linked_material_content`、`load_skill`、`read_expert_draft_section`、`write_section_body`、`write_character_state` | 大纲 `outline`、正文编写 `draft` | 正文片段 `draft_excerpt` |

### 4.2 剧本写入规则

- 写入工具默认操作当前智能体对应阶段；人物、大纲等普通阶段无需传 `target_stage_id`。
- 剧情智能体处于父阶段 `plot_design` 时，`target_stage_id` 仅供选择剧情子方向（`plot_design` 或 `plot_refine`）；省略时写入当前选中的剧情子方向。
- 正文阶段不挂载 `write_workspace_editor`，仅提供 `replace_current_stage_text` 做局部替换。
- 剧本没有独立 `intro_design` 可见槽位；开篇钩子并入剧情设计。
- 剧本 `start_expert_writing` 默认会写全部正文小节，不跳过第一节。
- 剧本 `write_single_expert_section` 可单独写一个已初始化小节；目标 `section_id` 不存在时会提醒先初始化正文列表。
- 剧本分节写手提示词要求正文产出严格遵守剧本格式。

## 5. 技能加载对应关系

`load_skill` 只读取当前书籍绑定的技能库，且只允许加载当前智能体所属阶段的技能。技能正文开头必须包含 front matter：

```markdown
---
name: 技能名
description: 技能描述
---
```

当前可加载技能阶段：

| 智能体/阶段 | 实际加载的技能阶段 | 中文含义 |
| --- | --- | --- |
| `character_design` | `character_design` | 人物设计技能 |
| `plot_design` | `plot_design` | 剧情技能 |
| `intro_design`、`plot_refine` | `plot_design` | 剧情技能 |
| `outline` | `outline` | 大纲技能 |
| `expert_draft_coordinator` | `draft` | 正文专家编写技能 |
| `expert_section_writer` | `expert_section_writer` | 分节写手技能 |

## 6. 读取范围与配置来源

创作空间读取范围有两层来源：

1. 默认读取范围来自 `app/prompt_defaults/short/shared/read_access.json` 和 `app/prompt_defaults/script/shared/read_access.json`。
2. 用户在「创作空间设置」页修改后，会保存到本地 `.data/preferences.json`，运行时优先读取该配置，再由前端按当前书籍类型归一化。

归一化规则：

- 当前只保留 5 个 Agent ID：`character_design`、`plot_design`、`outline`、`expert_draft_coordinator`、`expert_section_writer`。
- 旧的 `intro_design`、`plot_refine` 读取配置会合并到 `plot_design`。
- 每个智能体必须能读取自己的必需阶段，例如正文专家总控和分节写手必须能读取 `draft`。
- 配置只影响读取类工具和提示词可见上下文，不改变写入工具本身的存在。
